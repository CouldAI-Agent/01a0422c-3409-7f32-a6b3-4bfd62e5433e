# Drive App Clone

A responsive Flutter application for file management, providing a "Google Drive"-like interface for exploring documents and folders on mobile, desktop, and web platforms.

## Features
- **Responsive Layout**: Adopts a side-by-side drawer and grid on desktop, and a classic hamburger menu on mobile sizes.
- **Adaptive Grid**: The file and folder grid automatically calculates columns based on available space to always provide the best reading experience.
- **Mock Data Layer**: Built with a clean separation of concerns using a mock data service, preparing the app for an easy backend swap.
- **Cross-platform**: Runs on iOS, Android, macOS, Windows, Linux, and Web natively.

## Running the Project
1. Run `flutter pub get` to fetch dependencies.
2. Run `flutter run` to launch the app on your preferred platform.
